<h1>Curso completo de JavaScript com ES6</h1>

<p>Repositório criado para armazenar os códigos, anotações, desafios e o projeto prático desenvolvidos durante o curso **JavaScript Completo ES6** da [Origamid](https://www.origamid.com/), ministrado pelo instrutor André Rafael.

O objetivo deste treinamento é dominar o JavaScript do básico ao avançado, aplicando os conceitos na web por meio de manipulação da árvore DOM e consumo de APIs externas utilizando os padrões mais modernos do EcmaScript (ES6+).</p>
